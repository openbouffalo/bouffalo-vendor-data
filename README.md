# Bouffalo Vendor Data

This repository is collection of gathered materials for Bouffalo chips, provided by vendor.
It contains register headers, memory maps, interrupt definitions, or any other description, describing the hardware.
All files were gathered from various public sources. You can find the source in `<chip>/SOURCES.md` files.

This repository provides only what is provided by vendor, with minimal clean-up and fixes.
Community maintained documentation and material is stored in `<to be done>` repository.
